TAKUYA PORTFOLIO - 更新用ファイル一式

【重要】
このフォルダは、GitHub Pagesで公開中の takuya-portfolio を更新するためのファイルです。
実際の作品画像は含まれていません。ご自身の画像を assets フォルダに入れてからアップロードしてください。

■ 画像の入れ方
1. このフォルダ内の assets フォルダを開きます。
2. 作品画像をコピーして、次のファイル名に変更します（拡張子も合わせます）。
   - bird-hunter.jpg       鳥型ハンター
   - water-simulation.jpg  水流シミュレーション
   - twilight-graveyard.jpg 黄昏の墓場
3. JPG以外（PNGなど）の画像を使う場合は、index.html内の該当する画像パスも変更してください。
   例：assets/bird-hunter.png
4. 複数の画像を載せたい場合は、画像を追加したうえで index.html の該当作品部分に img 要素を追加する必要があります。

■ GitHubへアップロード
1. https://github.com/kakinotanebit/takuya-portfolio を開く
2. Add file → Upload files を選ぶ
3. このフォルダの中にある index.html、style.css、script.js、README.txt と assets フォルダをアップロード
   ※ assetsフォルダを開いて画像だけを別々にアップロードするのではなく、フォルダ構造を保ったままアップロードするのが重要です。
   ※ GitHubの画面でフォルダごとドラッグできない場合は、先に assets フォルダをリポジトリに作成し、画像をそこへアップロードしてください。
4. Commit changes を押します。
5. 1〜5分ほど待ち、公開URLを開いて確認します。
   https://kakinotanebit.github.io/takuya-portfolio/

■ 作品説明について
文章はポートフォリオ用のたたき台です。実際に担当した工程・使用ソフト・制作期間に合わせて必ず修正してください。
「Maya ※使用ソフトに合わせて修正」のタグも、実際の使用ソフトに合わせて変更してください。
